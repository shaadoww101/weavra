07 / QUESTIONS

A few things worth knowing.

Is this the live or demo version?
Check the badge at the top. With an LLM key set (see README) chat is live AI grounded in the knowledge base. Without a key it runs in clearly-labelled DEMO MODE, answering from the seeded knowledge.

Can I add my own knowledge?
Yes — use the Knowledge Base form above, or POST /api/knowledge. New documents are searchable immediately.

Do workflows really pause for approval?
Yes. An Approval step pauses the run with status waiting_approval until POST /api/workflows/:id/approve (or the Approve button) is used.
